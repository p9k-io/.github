# p9k

p9k builds and runs AI products by [Prokop Simek](https://github.com/prokopsimek), from Prague.

## Products

| | |
|---|---|
| **[Záboj](https://zaboj.app)** | Voice AI assistant for the car. Talk while you drive, and Záboj answers out loud and acts through your tools: a meeting in the calendar, an email, a CRM note. Works on CarPlay, iPhone and in the browser. |
| **[Plantory](https://plantory.ai)** | Garden planning with AI. Plant recommendations, planting calendars and layout ideas for any space. |
| **[SmartStaff](https://smartstaff.io)** | AI colleagues for the work you don't have people for. They show you their plan first, start only after you approve it, and send back finished files. |

The source code is private. To get in touch, use the contact on each product's website.
