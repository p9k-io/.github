# Pokyny pro agenty

Tento **veřejný** repozitář obsahuje profil organizace p9k na GitHubu. `profile/README.md` je veřejná stránka organizace; její změna se projeví návštěvníkům.

- Před úpravou si přečti `README.md` a stávající profil. Uváděj pouze ověřená a zveřejnitelná fakta, odkazy a produktová tvrzení.
- Nevkládej interní infrastrukturu, přístupy, neveřejné obchodní informace, osobní údaje ani tajemství. Při nejistotě si ověř zdroj a oprávnění ke zveřejnění.
- Zachovej jazyk a účel stávajícího profilu, pokud zadání neurčuje jinak. Po změně zkontroluj Markdown a funkčnost změněných odkazů.
